# github-analyzer

## 简介

GitHub 开源项目分析与评估 Skill。当你在博客 / 微博 / 小红书 / X thread 上看到提到 GitHub 项目时,用它快速得到一份实用评估报告 → 落盘形成可回溯的开源工具知识库。

## 解决什么问题

刷 Twitter、公众号、V2EX 时经常看到别人推荐 GitHub 项目,但:
- 不知道这个项目适不适合自己
- 不清楚社区真实评价、有没有 archived / AGPL / 安全公告这类坑
- 懒得自己查 Star 数、活跃度、竞品对比
- 多个项目一起看时不知道优先装哪个
- 上次看过的项目,几个月后想回顾结论得重头来

这个 skill 一次性搞定:**意图驱动报告侧重 + 量化评分 + 风险横幅 + 持久化知识库**。

## 功能

### 1. 多来源输入识别

支持五种输入形式,自动判断处理方式:
- 单一 GitHub 链接(`github.com/owner/repo`)
- 截图(自动识别页面类型:repo 主页 / issue / PR / profile / 第三方转发)
- 文章 / thread / 帖子里提到多个 repo(自动抽取列表 + 让你勾选)
- 文字描述(WebSearch 找候选)
- 仓库名(`owner/repo` 字符串)

### 2. 意图驱动报告

让你选评估意图,报告侧重对应维度:

- 🛠 **想装来用** → 详写安装步骤、依赖、与现有工具冲突、上手难度
- 📚 **想学架构** → 详写代码结构、文档质量、设计选择、推荐阅读顺序
- 💡 **想抄思路** → 详写核心机制、关键算法、设计 trade-off
- 🗺 **看赛道** → 详写竞品矩阵、生态位、社区趋势

### 3. 风险体检(必查)

报告头部置顶 ⚠️ 横幅:
- `archived` / `disabled` → 「已归档,谨慎使用」
- License 是 AGPL/GPL → 「传染性 license,商用前先看条款」
- 无 License → 「法律上默认禁止再分发」
- 公开 security advisories → 「有未修复安全公告」
- fork 且原项目活跃 → 「建议看原项目」

### 4. 量化评分(6 维)

| 维度 | 说明 |
|------|------|
| 需求相关度 | 与你意图 + 现有工具的匹配 |
| 项目成熟度 | 活跃度 + 贡献者分散度 + Issue 处理质量 |
| 上手成本(反向) | 安装 + 学习曲线,越低分越高 |
| 现有体系互补性 | 与已装 skill / 工具的重叠度 |
| 长期维护信心 | 贡献者分散度 + 商业模式可持续性 |
| 用户视角风险(反向) | License / 安全 / 隐私 / 远程依赖 |

### 5. 准活跃度判定

用 GitHub `stats/commit_activity` 端点(过去 52 周周提交数),不是看最近 5 个 commit。判定三档:
- **活跃**(过去 90 天 > 20 commit)
- **低活跃**(1-20)
- **僵尸**(0)

报告里直接给「近 4w / 近 12w / 近 52w」三个数字。

### 6. 结构化竞品对比

至少 2 个竞品的表格:Star / 最近更新 / 安装难度 / 核心差异 / 适合谁。

### 7. 用户环境感知

启动子 agent 前先扫 `~/.claude/skills/`、`~/.claude/agents/`、ai-os skill 索引、桌面项目目录,注入「用户环境摘要」到每个子 agent prompt,使「互补性」分析有据可依。

### 8. 持久化知识库

每个项目分析完都写到 `00_全局资产/github-analyzer/YYYY-MM-DD-{owner}-{repo}.md`,并维护 `INDEX.md` 索引表。第二次见到同一 repo 时先查历史,可以「用上次结论」、「重做」或「差量分析」。

### 9. 轻量入口 / 重量入口分流

- **轻量入口**(裸链接触发):30 秒速览 5 行(定位 / Stars / 活跃度 / License / 一句话结论),不写盘,问你要不要升级到完整流程
- **重量入口**(带动词或多项目场景):完整 3 agent 并行 + 落盘报告 + 写 INDEX

### 10. gh CLI fallback

优先用 `gh api`(已认证 5000 次/小时)。如果 `gh` 未安装或未 auth,自动 fallback 到 `curl`(限速 60/h,够单次分析),并在报告末尾提示安装。

## 触发条件

- 直接发 GitHub 链接(裸链接走轻量入口)
- 「帮我看看这个项目」、「这个开源项目怎么样」、「评估一下这个工具」
- 「这个项目值不值得装」、「这篇文章里提到的项目都给我看看」
- 「这个 thread 提到的工具帮我筛一下」
- 分享 GitHub 页面截图、文章/thread/帖子里提到一个或多个项目

## 不适用场景

- 纯代码审查(review 自己的代码)
- 创建新项目(开发任务)
- 简单搜索查询

## 报告示例

```markdown
# graphify 分析报告

**日期**:2026-05-17
**意图**:🛠 想装来用

> License = MIT(无明显风险)

## 一句话结论
项目知识图谱生成器,冷启动利器

## 项目概览
- **定位**:把代码库转成可查询的知识图谱,支持 20+ AI 平台
- **Stars / Forks**:48k / 2.1k
- **活跃度**:活跃 — 近 4w: 24 commit · 近 12w: 78 · 近 52w: 380
- **License**:MIT(随便用)

## 综合评分
| 维度 | 分数 |
|------|------|
| 需求相关度 | 7/10 |
| 项目成熟度 | 6/10 |
| 上手成本(反向) | 9/10 |
| 现有体系互补性 | 7/10 |
| 长期维护信心 | 5/10 |
| 用户视角风险(反向) | 10/10 |
| **加权总分** | **7.3/10** |

## 建议
**可选** — 等正式版再深度依赖,先在中等项目上试用
```

```markdown
| 排名 | 项目 | ⭐ | 总分 | 建议 | 风险 | 一句话理由 |
|------|------|-----|------|------|------|-----------|
| 1 | caveman | 61k | 8.5 | 推荐 | 无 | 省 65% token |
| 2 | graphify | 48k | 7.3 | 可选 | 无 | 冷启动利器 |
| 3 | some-tool | 200 | 8.2 | 推荐 | AGPL | 精准解决需求 |
```

行动建议:**立即安装** / **观察等待** / **暂不考虑** / **谨慎**(有风险横幅)。

## 安装

```bash
mkdir -p ~/.claude/skills/github-analyzer
curl -o ~/.claude/skills/github-analyzer/SKILL.md \
  https://raw.githubusercontent.com/shaocong1987-collab/shaocong-skills/main/github-analyzer/SKILL.md
```

## 配合使用

跟 `idea-to-prompt` 和 `project-init` 形成完整链路:

- `github-analyzer` — 评估外部工具值不值得装/学/抄
- `idea-to-prompt` — 把想法变成可粘贴的 prompt
- `project-init` — 把 prompt 落地为项目骨架
