# digital-employee-forge — 数字员工铸造

蒸馏人类员工成数字分身 skill(逼近 100% 还原)。把一个真实员工 + 他的数据(录音/微信/工作产物/访谈),经七阶段产线,变成该员工的数字分身 skill set(1 个人设 skill + N 个能力 skill),每条知识带 L1-L4 证据分级。

## 用法

见 `SKILL.md`。第一次落地建议:选一个数据最全、你最熟的员工的**单一能力域**(如"报价判断")走「闪电档」pilot,流程跑通 + 还原度达标,再扩到全职责。

## 文件

- `SKILL.md` — 主流程(七阶段 + 还原度量化 + 合规)
- `templates/SKILL.md.template` — 分身单 skill 产出格式(RIA++ + L1-L4)
- `templates/L1-L4证据分级.md` — 证据级规范(还原度核心指标)

## 核心信念

- 蒸馏 ≠ 总结。是产出 agent 可调用的活模块(有触发条件 + 执行步骤 + 边界)。
- 替代级目标:瞄准 100% 还原才逼出极限保真;诚实承认 85-90% 可达,最后 10-15% 靠人机协同。

## 归属:二次创作(站在前辈 skill 肩上)

本 skill 不是任何单一 skill 的复制,而是把多个社区 skill 的核心机制**编排**成一条面向真实企业员工的蒸馏产线。原始思想归属:

| 机制 | 来源 skill | 备注 |
|---|---|---|
| 人设蒸馏 | nuwa(女娲造人) | 花叔(huashu)|
| 方法论蒸馏 / 三重验证 / 压力测试 | cangjie(仓颉) | 社区 skill,出处见推荐清单 |
| L1-L4 证据分级 | anyone | 社区 skill,出处见推荐清单 |
| 差异反馈进化闭环 | darwin / EvoSkill | 社区 skill,出处见推荐清单 |
| 决策质量验证 | skill-eval | 社区 skill,出处见推荐清单 |

> 部分来源仓库链接仍在核实,详见本仓库 `推荐给覃朝瑞.md` 的「参考/致谢」清单。**本 skill 原创的是"产线化编排"这一层,底层机制的功劳属于上述原作者。欢迎原作者认领补全出处。**

## 风险红线

隐蔽蒸馏:不挂真人名 / 不克隆声音 / 蒸馏方法论非个人特征 / 商业化前脱敏或授权。详见 SKILL.md「合规与风险」。
