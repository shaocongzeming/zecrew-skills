# L1-L4 证据分级规范

蒸馏每条知识必须标证据级,决定可信度 + 还原度。来自 anyone-skill 机制。

## 分级定义

| 级别 | 含义 | 来源 | 可信度 | 分身输出用法 |
|---|---|---|---|---|
| **L1** | 员工原话直接引用 | 录音逐字稿 / 文字原文 | 最高 | 可直接断言,带出处 |
| **L2** | 员工意思转述 | 改写了但保留原意 | 高 | 可断言,注明"转述" |
| **L3** | 多条数据归纳出的模式 | 跨场景归纳 | 中 | 标"通常/一般",需场景校验 |
| **L4** | AI 推测他大概会这么想 | 无直接证据,基于风格推测 | 低 | 标"推测",**必须真人复核** |

## 还原度 = L1 占比

| L1 占比 | 级别 | 含义 |
|---|---|---|
| ≥60% | 替代级 | 逼近 100% 还原,可独立上岗 |
| 30-60% | 辅助级 | 能搭手,关键决策转真人 |
| <30% | 数据不足 | 回阶段 1 补采数据 |

## 铁律

1. **L4 必须显式标注**,不能混在 L1-3 里当事实。分身输出带证据级标记,用户拍板知道哪些必须复核。
2. **隐蔽蒸馏优先产 L1**(工具日志/工作产物原文),L4 慎用(无访谈验证,推测易偏)。
3. **公开访谈数据**,员工原话标 L1,访谈者追问引导出的标 L2,多条归纳标 L3。
4. **证据级进 SKILL.md frontmatter**(`evidence_level` 字段)+ R 段落内标,双标。

## 与还原度报告的关系

`还原度报告.md` 必含:
- 总条数 / L1 条数 / L1 占比
- 各能力域的 L1 分布(哪个域还原高,哪个域数据缺)
- L4 条数清单(需真人复核项)

## 示例(化名「资深销售 T」演示,非真实人物)

```
# L1(原话)
source_quote: "这种客户你别急着报价,先问他预算框,框不出来就是忽悠你白干"
— 资深销售 T,YYYY-MM-DD 录音

# L2(转述)
source_quote: T 的意思是,没预算框的客户大概率是白干活(YYYY-MM-DD 录音转述)

# L3(归纳)
summary: 跨 5 次报价案例归纳——压价客户共性是"不给预算框 + 催快出价"

# L4(推测)
summary: 推测 T 遇到甲方直询底价时,会先用"最近有个类似项目"试探对方预算带(无直接录音,基于其风格推测)⚠️需复核
```
