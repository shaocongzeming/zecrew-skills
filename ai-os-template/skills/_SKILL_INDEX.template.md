> 使用方法: 复制成 `~/.ai-os/skills/_SKILL_INDEX.md`,随着 Skill 增加逐行登记。
> 最后核验: YYYY-MM-DD

| 状态 | 含义 |
|---|---|
| candidate | 候选,还没证明确实需要 |
| active | 过去 4 周内真实使用过 |
| deprecated | 已废弃,保留记录 |
| merged | 已合并到其他 Skill |

## Skill 创建门槛

满足任一条件才创建:

- 同一动作重复出现 3 次。
- 同类失败出现 2 次以上。
- 某项任务有明确输入、流程、输出、验收标准。
- 不沉淀会导致明显业务损失或重复劳动。

## Skill 删除门槛

满足任一条件应删除或合并:

- 8 周没有使用。
- 触发词和其他 Skill 冲突。
- 输出质量长期不可验证。
- 已经被项目代码、自动化或 SOP 取代。

## 触发词冲突处理

当多个 Skill 匹配同一触发词时:

1. 具体 Skill 优先于通用 Skill。
2. 优先级不清时,反问用户一次,不要默认猜。
3. 反问 2 次仍歧义,写入 `failures/_ai-use-failure-log.md`,周复盘决议合并或拆分。
