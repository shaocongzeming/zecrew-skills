# 项目开发日志

> 用途: 每个项目的唯一上下文入口。
> 原则: 新会话先读本文件,开发完成后更新本文件。
> 创建日期: YYYY-MM-DD
> 最后更新: YYYY-MM-DD

## 智能体唯一启动入口

### 给用户的一句话指令

```text
请先读取 [本项目路径]/项目开发日志.md,然后基于里面的上下文直接继续开发。
```

如果涉及本地网页:

```text
请先读取 [本项目路径]/项目开发日志.md,然后修改 [本地网页 URL] 对应的前端内容,完成后启动服务验证,并更新项目开发日志。
```

### 智能体读完本日志后的默认工作方式

- 本文件是项目唯一上下文入口。读完本日志后,按目录地图读取必要代码、资料和验证说明。
- 如果任务不明确,先根据本日志里的项目原则做保守判断;只有会影响业务正确性、安全边界或关键交付时才提问。
- 不要跳过验证。涉及网页、交互、数据、接口或规则时,必须按本日志的验证方式检查。
- 完成开发后必须在"开发记录"里追加当天记录:
  - 改了什么
  - 改了哪些文件
  - 如何验证
  - 还有什么风险或下一步
- 稳定改动完成后,根据项目规则建议是否提交 Git;不要自动 push。
