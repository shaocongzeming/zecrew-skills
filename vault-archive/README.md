# vault-archive

结束对话时,一句「归档」把这次对话沉淀进你的 Obsidian / Markdown 知识库,让 AI 助手的记忆跨会话累积。

## 它做四件事

1. **对话日志** —— 把本次对话写成结构化归档(主题 / 做了什么 / 决策 / 踩坑 / 偏好 / 待跟进)。
2. **次日日记** —— 第二天首次对话时,助手以第一人称回顾昨天全天,写一篇有温度的日记(人格生长层,不是流水账)。
3. **作战室(状态真相源)** —— 更新"每条战线做到哪 / 下一步 / 卡点",只增不减。
4. **用户画像学习闭环** —— 把你明确的纠正(硬记录)和观察到的偏好(软记录)沉淀进画像,≥3 次的观察自动升级为正式结论。

## 用法

配置知识库根目录(默认 `~/ObsidianVault`),把 `[助手名]`/`[用户名]` 换成你自己的设定,然后对话结束时说「归档 / 存档 / 保存对话 / 收尾」即可。

```bash
: "${VAULT:=$HOME/ObsidianVault}"
```

## 搭配

与本仓库 `ai-os-template` 配套使用效果最佳(作战室 + 画像的目录结构和加载规则在那边)。单用也行,按你的库结构改路径即可。
